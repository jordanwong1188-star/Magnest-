# MagnaNest Store

Single-product storefront for MagnaNest magnetic refrigerator storage.

## Stack
HTML5, Tailwind CDN, custom CSS, vanilla JavaScript, Netlify hosting. Shopify is intended as the production checkout/order layer and CJdropshipping as the fulfillment layer.

## Launch status
The responsive storefront, bundle pricing, cart drawer, quantity controls, shipping threshold and checkout summary are functional. Checkout is intentionally a preview until a real Shopify product is connected. Replace lifestyle stock images with exact supplier sample photography before paid advertising.
